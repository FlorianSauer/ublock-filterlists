! Anchor policy: ARIA roles, href paths, DOM structure. No text anchors
! (the site is multi-lingual), no generated class names.

! ---------- Cookie banner ----------
! Tumblr's CMP full-screen overlay (vendor library class, not a build hash):
tumblr.com##.cmp-components-modal__screen-overlay
! Harder, survives CMP class renames (the path prefix outlives
! cmp-23 -> cmp-24); uncomment if the class-based rule ever breaks:
!tumblr.com##||assets.tumblr.com/pop/vendor/cmp-$script

! ---------- Scroll login dialog ----------
! aria-modal + role + auth links (language independent):
tumblr.com##div[role="dialog"][aria-modal="true"]:has(a[href^="/auth/"])

! ---------- Pitch component ----------
! Hits both variants: the fixed bottom nag bar and the right sign-up box.
! Anchored on the bolded pitch fragment (strong) plus a button with
! aria-label; :upward(1) takes the colored frame with it (otherwise an
! empty colored strip stays visible). Measured: exactly 2 hits,
! 0 false positives on a permalink login-wall page.
tumblr.com##div:has(> div > strong):has(> div > button[aria-label]):upward(1)

! ---------- Scroll lock ----------
! The dialog injects <style>body{overflow:hidden;padding-right:8px}</style>
! into its own tree, which keeps applying while the dialog is hidden:
tumblr.com##body:style(overflow: auto !important; padding-right: 0 !important)
